Brainstorm — three jobs, one data source
01 · Built above
Add / remove hostels

A list of names + coordinates is the source of truth — the map draws itself, no redrawing in Illustrator. Export the SVG and every piece is a named layer in Figma.

Later: the WordPress theme reads each hostel's lat/lng and renders this SVG live — add a hostel in WP and its pin appears on the island.

Tools: this editor · Figma · WordPress (PHP loop)
02 · Built above
Attraction & theme maps

Same island base, different data layer: attractions, surf spots, hikes, guachinches, events. Each category gets an icon; the 1080×1080 artboard is ready for Instagram and blog guides.

Icons are Lucide stand-ins — send the original line-icon set (volcano, hiker, lighthouse…) and I'll swap them in 1:1.

Tools: this editor · Figma for campaign layouts

Yes — Leaflet. Free, ~40 KB, no API key, easy to drop into WordPress. Real streets you can pan and zoom, brand-styled pin, and 5 / 10 / 15-min walking rings that echo the island halos.
